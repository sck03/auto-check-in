## 资源与维护

- 浏览器请求按字节流式限制为 1 MiB，已提交操作的超限响应仍保持结果不明，禁止自动重放。
- 会话文本总量限制 2 MiB、localStorage 最多 2048 项，过大快照在跨 CDP 传输前拒绝；原凭据保持可读。
- 可选容量接口只传资源范围与变化广播；满载浏览器任务保持排队，HTTP 不因此被一并领取阻塞。接口快照不替代驱动的最终信号量与取消约束。
- 桌面设置空闲轮询降为三十秒；账号每页五十项，选择改为 Set 查询，删除回收失效选择。
- 输入队列限制六十四个待发送事件/64 KiB，单次文字最多 4096 字节，超限后核对再继续。
- 离开账号页后迟到创建的登录会话自动取消，避免无人操作仍占浏览器名额。
- 状态复核、共享响应规则、浏览器请求/存储脚本、容量和目录回收各自封装，应用层不依赖 Chromium 或 SQLite 的具体类型。

## 清理范围

移除旧的布尔状态复核、重复的 Retry-After 实现和整响应无界读取。保留有引用的脚本、许可、图标源、历史验收文档及构建工具。旧版本构建包、过期测试日志与无用报告在新构建验收后清理；用户 data、密钥、备份不纳入生成文件清理。

本地已将 13 组旧 SDK、1.0.5 安装包、打包中间目录和历史日志集中移动到 `_cleanup_pending/20261024-optimization/`，附 `sources.json` 与 README，供用户手动删除。当前 `.tools/go` 已替换并核实为 Go 1.27.3；1.0.6 安装包和当前可执行文件保留在 dist，用户数据未移动。待清理目录被 Git 忽略。
