# 2026-10-24 稳定性维护

后续源码 1.0.6 的完整分析与优化见 [优化维护记录](optimization-20261024.md)。本页保留前一轮稳定性维护的实现与当时验证结果。

源码版本以 `internal/buildinfo/VERSION` 为准，数据库格式仍为 v5。本次提交到 main，不自动创建发布标签。

## 修复

| 问题 | 最终行为 | 模块 |
| --- | --- | --- |
| 身份不符后快照覆盖用户 ID | 仅保存确认的同一身份；重新登录和存储层也复核已绑定 ID | provider / store / app |
| 结果保存超时复用失效上下文，账号长期 running | 独立 fallback 截止时间；持久化仍失败时只恢复本地结束记录，不重放站点操作 | app/persistence.go |
| 同站点等待占满 worker | 领取时排除忙碌 origin，等待任务保留 queued，空闲名额可执行其他站点 | app/dispatch.go / store |
| 默认端口与 location.origin 不一致 | 统一 HTTP 80 / HTTPS 443 表示，兼容已有 v5 站点和 localStorage 键 | domain / store |
| 崩溃留下浏览器 profile | 独占启动时回收已知目录；保护普通文件、未知目录和符号链接 | browser / bootstrap |
| 桌面设置旧 GET 覆盖保存结果 | 可取消读取、保存前中断旧请求、隐藏或卸载停止轮询 | useDesktopSettings |
| 输入队列吞错后仍可保存 | 失败停止后续输入和保存；用户核对后显式继续，不自动重放 | inputQueue / BrowserDialog |
| 点击登录后立即保存偶发 401 | 先刷新身份，最多两秒只读复核；身份不符、验证页和异常响应立即停止 | app/login_verify.go |
| 版本与发布对象漂移 | 单一 VERSION，发布标签必须匹配，构建明确检出该标签 | buildinfo / scripts / workflows |

原有账号锁、每日预算、自动窗口截止、Unknown 状态人工核对和凭据脱敏继续适用。结果恢复队列保留原结束时间，不保存凭据；进程崩溃后仍以持久记录恢复为中断，不猜测远端是否生效。

## 维护与清理

- 结果写回、origin 调度、登录验证分别独立，站点适配器不依赖 SQLite、桌面或界面。
- `diagnostics` 增加待恢复记录数、写回失败数和启动 profile 回收计数，不扫描账号目录大小、不新增常驻磁盘扫描。
- 历史保留实际删除记录后 checkpoint WAL；主库空闲页继续复用，避免自动全库 VACUUM 阻塞任务。
- 移除仅供测试使用的生产导航包装、未使用的暂停图标和重复的前端包版本；保留仍有引用的样式、构建工具及历史验收说明。
- 不删除用户数据库、密钥、备份或仍用于构建的工具链。测试报告与生成产物不进入 Git。
- 网页与 Windows 烟测成功后等待实例退出并删除自身临时数据目录；失败时保留现场。避免日常回归持续积累测试数据库和密钥。
- 本地过期测试实例、旧构建包和旧报告已移入被 Git 忽略的 `待手动清理/20261024/`，附来源清单，供手动删除；当前构建、用户数据和工具链保留。

## 验证边界

本轮使用本地模拟站点及隔离 Chromium，不向真实账号提交测试请求。Linux 与 Docker 的实际运行以推送后的 Verify 为准；Windows 托盘和开机运行测试使用隔离配置，不更改用户真实自启动项。详细命令和通用限制见 [验证说明](testing.md)。

本地验证：全量 Go 测试、含 Chromium 的竞态检测、`go vet`、TypeScript 与生产构建、27 项网页端到端、Windows 托盘烟测、Windows/Linux 打包、actionlint 均通过。另以真实 SQLite 写锁复现结果写回失败，验证恢复后释放账号且不重放站点操作；原有纯内存虚拟时钟测试覆盖独立截止时间和空队列零轮询。
