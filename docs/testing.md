# 验证说明

## 自动化范围

- 1.0.6 补充：整句已签到确认与否定/查询失败文本、状态接口限流后零 POST、旧 GET 兼容及验证页例外、Cookie 轮换/删除/重开、数字与日期 Retry-After。
- 资源预算：真实 Chromium 覆盖 UTF-8 流式响应、超量 GET/POST 和 localStorage；领域校验 Cookie 与存储合计总量，虚拟时钟验证目录失败恢复后零轮询。容量满载时 HTTP 先执行、浏览器保持 queued，释放广播后自动继续。
- 网页回归现为 31 项，增加慢保存时字段锁定、1000 账号仅渲染 50 行并正确筛选/选择、离开页面后结束迟到登录、输入积压限制及核对后恢复。桌面设置虚拟时间改为 30 秒周期，隐藏或离开仍停止读取。
- CI 检查 Go 1.27.3 的可达漏洞；Release 复用目标提交 Verify，并在两个架构和归档校验通过后按 digest 推广正式镜像标签。

- 2026-10-24 稳定性补充：错账号响应连续两次均不更新会话或发送签到，重新登录也复核绑定身份；存储层拒绝身份漂移。
- 结果写回：首个上下文超时后使用独立 fallback 截止时间，两次失败后无需重启恢复本地结束记录，空恢复队列经过 24 小时不轮询；终态幂等且不覆盖成功结果。
- 调度公平性：三个同站点任务排在另一站点前，前一个仍运行时另一站点即可开始；同 origin 的不同站点配置都遵守排除规则。
- URL 与资源：HTTP 80、HTTPS 443、IPv6 默认端口归一化；已有 v5 数据与 localStorage 键兼容；异常 profile 只清理已知名称的目录，保护普通文件、未知目录及符号链接目标。
- 前端及登录：桌面设置的旧 GET 不覆盖新 PUT、隐藏和卸载后停止读取；输入失败中断队列且禁止保存，核对后继续不重放；延迟 600 毫秒的站点登录可立即保存，401 仅有限只读复核，身份不符不重试。

- 领域规则：北京时间窗口、按账号独立随机、重启稳定性、成功后的日期边界、补签截止和非法配置。
- 站点协议：严格 JSON、成功/已签到、AnyRouter 只访问、AgentRouter 新登录与不注销导入会话、New API 状态复核、薄荷每日抽奖与令牌失效、HTML 假成功、401、429、余额与奖励分离。
- 存储：AEAD 加密、账号关联验证、版本冲突、并发入队唯一性、有限重试和重启预算、异常退出、备份事务回滚。
- HTTP：访问鉴权、来源校验、未知字段、请求大小、静态页面与 API 分离、账号读回脱敏。
- 执行器：总并发与同 origin 串行、异常退出归一化、通知唤醒。
- 真实 Chromium：Cookie 恢复、密码登录、GitHub/LinuxDo 同页跳转和新页授权、授权返回及会话保存、多账号页面与 Cookie 隔离、共享进程与空闲回收。
- Windows：当前用户启动注册适配器（隔离测试键）、偏好持久化/冲突/回滚。
- 网页回归：站点/账号新增、签到与防重复、编辑保留凭据、人工浏览器登录、高延迟连续输入、保存与刷新并发、退出后的迟到响应、完整响应体超时、加密备份恢复。
- 浏览器生命周期：不响应 CDP 的子进程、等待启动的账号取消、诊断查询不阻塞、临时目录与会话名额释放；恢复的 localStorage 不会覆盖后续登录或退出状态。
- 浏览器空闲：关闭账号页面及 OAuth 弹窗后，模拟站点的轮询请求停止；覆盖后台池保留与可见进程关闭两种情况。
- 登录回归：延迟渲染且只有 id 的输入框、提交后立即跳转导致响应体丢失、有效会话不重复登录、薄荷 userToken 保存和恢复、可见人工窗口不启用自动化标记。
- 执行记录：手动密码失败显示原始业务原因、登录阶段、HTTP 状态与建议；密码脱敏；08:00 前的跳过不消耗正常计划。
- 调度截止：首次与补签队列到点取消，运行中任务及失败后的复核共用截止时间。
- 数据目录：默认跟随可执行文件，环境变量和参数覆盖；全新初始化、同版本重开、旧版或更高版本数据库拒绝打开并提示使用空目录。
- 存储稳定性：连接重建后外键与等待超时有效，路径含中文、空格或 URI 特殊字符仍可重开；新建站点关联、队列与每日预算索引，查询计划验证站点账号查询使用索引，过期队列不拖延手动任务，缩减重试预算后不再重复扫描。
- 历史界面：筛选重置分页只查询一次，筛选变更和离开页面时中止旧查询，慢速读取期间连续刷新合并为一次后续请求；设置页展示实际数据路径。
- 模板管理：四种模板统一命名和分组；通用模板包含接口和网页按钮两种签到方式，编辑及备份恢复保留自定义配置；有账号引用时禁止切换签到方式；旧模板和无模板请求拒绝保存。
- 网页按钮签到：等待延迟启用的按钮、识别已完成状态、跨导航恢复只读检查、点击响应丢失时保持结果不明且禁止自动重试；状态检测每 200 毫秒一次。
- 配置与会话：模板/适配器不匹配时拒绝保存，站点与账号事务共同保护 OAuth 执行方式；清除旧会话会移除旧 Token 和用户 ID，localStorage 登录可被正确识别。
- 刷新资源：虚拟时钟验证空闲 30 秒、运行中 5 秒、隐藏后零轮询和重新显示时立即刷新；打开的执行详情同步更新结果。
- Windows 实际程序：界面、版本、托盘状态、八项菜单、最小化、恢复、关闭留驻、暂停、开机开关联动、独立登录窗口显示/取消及零截图轮询、正常退出。
- 空闲调度：Go 虚拟时间经过 14 小时不再查询队列或扫描到期账号；修改计划立即重设定时器，准时入队且不重复唤醒；最近计划排除禁用、暂停和活跃账号。历史清理覆盖启动、北京时间零点、重复通知不清理和下一日再次清理。
- 托盘与系统通知：隐藏托盘经过 14 小时不刷新菜单；设置提交和备份恢复才广播设置变更，失败写入与任务活动不刷新菜单。Windows 模拟时间变化/恢复消息会唤醒监听，挂起消息不会；系统监听可反复启动、停止并释放资源。
- 自动网页识别：中英文签到文字、无障碍标签、延迟启用、多个候选、隐藏/禁用/跨站控件、错误 CSS、登录文字、普通成功提示和历史文字；点击后跳转及不确定结果不重复提交。
- 会话续期与 WONG：429/5xx、验证页面、无效响应、身份不符均不重复登录；明确失效才续期；`data.checked_in=true` 且禁止缓存时不重复提交签到。
- OAuth 重新登录：GitHub / LinuxDO 按配置自动选择入口，等待按钮启用；同页和弹窗回调后保存新会话，连续两次 AgentRouter 执行各只登录一次。CDP 拦截官方域名模拟授权页，验证延迟返回期间不会重复提交授权；不连接真实身份提供方。
- OAuth 页面识别：忽略页脚、隐藏和禁用控件；多个入口、错误 CSS、外站页面及不匹配的回调或 OAuth 事务不提交。覆盖 LinuxDO 无表单的“允许”链接、对应应用地址校验，以及两种方式的 OAuth 配置延迟。9 组 OAuth 页面回归加入原有 16 组，共 25 组。
- AgentRouter 会话确认：快速授权弹窗先建立监听再放行；成功登录后立即跳转、用户信息接口返回 WAF HTML 时仍可确认本次登录。旧缓存、清除用户信息或身份不符不能复用登录证据；人工登录与自动执行共用本站会话清理。
- 普通站点会话复用：AnyRouter 和 New API 的人工窗口保留旧 Cookie 与页面用户信息；真实 Chromium 验证有效会话不重新登录，401 失效后清除阻碍登录页的旧用户标记并仅发起一次 LinuxDO 登录。
- 管理窗口磁盘回收：预置旧组件文件，验证启动清除、最小化及关闭后目录删除、恢复窗口可用，以及数据库保留。测量窗口运行期间的目录大小。

## 命令

```powershell
go test -race ./internal/...
go vet ./...
$env:CHECKIN_BROWSER_TEST='1'
$env:CHECKIN_NATIVE_BROWSER_TEST='1' # 仅本地 Windows 桌面测试，打开隔离的测试窗口
go test -race -count=1 ./internal/browser
cd web
npm ci
npm run build
npm run test:e2e
cd ..
node scripts/native-smoke.mjs
# 300 个账号、15,000 条历史记录的列表查询基准
go test ./internal/store -run '^$' -bench BenchmarkAccountList -benchmem
```

端到端测试需要先生成 `dist/checkin-server.exe`（Linux 为 `dist/checkin-server`）。Windows 程序测试还需要 `dist/AutoCheckIn.exe`。测试目录在 `artifacts/`，与实际用户数据目录分开；成功后删除测试实例目录，失败时保留日志与现场，界面截图和 native-smoke 汇总继续保留。

## 证据

测试脚本生成 `artifacts/go-tests.jsonl`、`web/test-results/results.json`、`artifacts/native-smoke.json` 和界面 PNG。最新逐项状态见 [进度与验收](progress.md)。

2026-10-19 实测的托盘空闲状态：后台浏览器未运行，Go 堆 2,202,728 字节、13 个 goroutine。这是该次空白测试实例的**Go 已分配堆**，不是进程 RSS、总内存或所有电脑的保证。管理窗口运行期间目录为 22,205,371 字节（约 21 MiB），收起或关闭后目录消失；该样本不代表所有浏览器版本的大小上限。

## 边界

模拟站点通过不等于真实网站通过；开机开关测试通过不等于执行了整机重启。时间监听覆盖 Windows 模拟消息和资源生命周期，未实际修改系统时间或让整机休眠。本地没有 Docker 引擎，已在 GitHub 完成实际容器启动、Chromium 登录/签到和重启测试；每次提交的 Linux 验证结果以对应 Verify 为准。需后续完成真实账号协议/风控验收以及 Windows 实际登录自启动验收。

GitHub 的 Windows / Linux 验证开启无头浏览器集成测试和全部前端回归；失败时保留 Playwright 跟踪记录。前端构建同时检查未使用的变量和参数。本地额外验证 Windows 可见窗口。AgentRouter 的 GitHub / LinuxDO 真实账号验收结果见 [进度与验收](progress.md)，网站后续风控仍以实际响应为准。
